# Asset Record

A modern asset management application built with React, TypeScript, and Vite.

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Development

This project uses modern web technologies to ensure a fast and responsive experience.
